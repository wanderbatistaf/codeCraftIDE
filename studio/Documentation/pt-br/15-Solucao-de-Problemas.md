# 14 - Solução de Problemas

Problemas comuns:
- Backend offline: http://localhost:8000/api/health
- Erro "Failed to fetch": backend não está rodando
- CORS: backend precisa permitir http://localhost:9002
- Sem login: confirme AUTH_ENABLED e credenciais
- Terminal/DB sem conexão: revise host, porta e credenciais

Exemplo:
- Se o Console não mostra saída, verifique o backend com /api/health

Limitações conhecidas:
- Erros de rede podem impedir execução e busca
