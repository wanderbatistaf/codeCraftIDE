# 01 - Interface

Top Bar (menus):
- File: projetos, abrir arquivos/pastas, criar arquivos/pastas, salvar
- Edit: undo/redo, cut/copy/paste
- View: Command Palette
- Run: compilar e converter
- Database: gerenciar conexões
- Help: About (Documentation aparece aqui)

Sidebar esquerda:
- Explorer: árvore de arquivos
- Database Explorer: tabelas e colunas do banco ativo

Área central:
- Tabs com arquivos abertos
- Editor Monaco
- Preview de formulários (para .per)
- Editor Lycia (para .fm2)

Bottom Panel:
- Console: saída da execução 4GL
- Terminal: SSH (usa credenciais do banco)
- Debug: placeholder
- SQL Query: editor e resultados

Exemplo:
- Abra o menu Run e veja as opções de compilação/conversão.
- Abra o Bottom Panel e alterne entre Console, Terminal e SQL Query.

Limitações conhecidas:
- Aba Debug é placeholder (funcionalidades futuras)
