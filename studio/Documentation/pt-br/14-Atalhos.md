# 14 - Atalhos

## Geral
- Ctrl+P / Cmd+P: Command Palette
- Ctrl+Shift+H / Cmd+Shift+H: Documentação

## Arquivos
- Ctrl+S / Cmd+S: Salvar arquivo atual
- Ctrl+Shift+S / Cmd+Shift+S: Salvar todos os arquivos

## SQL Query
- Ctrl+Enter: Executar consulta SQL

## Editor (Monaco)
- F1: Command Palette do Editor
- Ctrl+F / Cmd+F: Buscar
- Ctrl+H / Cmd+H: Buscar e Substituir
- Ctrl+G: Ir para linha
- Ctrl+/ / Cmd+/: Alternar comentário

Exemplo:
- Use Ctrl+P para abrir arquivos rapidamente pelo nome
- Use Ctrl+Shift+H para abrir a documentação

Limitações conhecidas:
- Alguns atalhos variam por sistema operacional
- O editor Monaco tem atalhos próprios que podem sobrescrever os globais
