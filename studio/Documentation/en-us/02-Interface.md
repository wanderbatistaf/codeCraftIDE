# 01 - Interface

Top Bar (menus):
- File: projects, open files/folders, create files/folders, save
- Edit: undo/redo, cut/copy/paste
- View: Command Palette
- Run: compile and convert
- Database: manage connections
- Help: About (Documentation appears here)

Left sidebar:
- Explorer: file tree
- Database Explorer: tables and columns from the active DB

Main area:
- Tabs with open files
- Monaco editor
- Form preview (for .per)
- Lycia editor (for .fm2)

Bottom Panel:
- Console: 4GL execution output
- Terminal: SSH (uses DB credentials)
- Debug: placeholder
- SQL Query: editor and results

Example:
- Open the Run menu and see compile/convert options.
- Open Bottom Panel and switch between Console, Terminal, and SQL Query.

Known limitations:
- Debug tab is a placeholder (future features)
