# 14 - Troubleshooting

Common issues:
- Backend offline: http://localhost:8000/api/health
- "Failed to fetch": backend not running
- CORS: backend must allow http://localhost:9002
- Login issues: check AUTH_ENABLED and credentials
- Terminal/DB connection: verify host, port, credentials

Example:
- If Console shows no output, check backend health

Known limitations:
- Network errors can block execution and search
