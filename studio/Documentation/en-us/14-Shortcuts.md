# 14 - Shortcuts

## General
- Ctrl+P / Cmd+P: Command Palette
- Ctrl+Shift+H / Cmd+Shift+H: Documentation

## Files
- Ctrl+S / Cmd+S: Save current file
- Ctrl+Shift+S / Cmd+Shift+S: Save all files

## SQL Query
- Ctrl+Enter: Execute SQL query

## Editor (Monaco)
- F1: Editor Command Palette
- Ctrl+F / Cmd+F: Find
- Ctrl+H / Cmd+H: Find and Replace
- Ctrl+G: Go to line
- Ctrl+/ / Cmd+/: Toggle comment

Example:
- Use Ctrl+P to quickly open files by name
- Use Ctrl+Shift+H to open the documentation

Known limitations:
- Some shortcuts vary by OS
- Monaco editor has its own shortcuts that may override global ones
